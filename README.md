## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the correct locations.
4. Keep the CV PDF in the location specified by its HTML link.
5. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Deployment with GitHub Pages

1. Create a public GitHub repository.
2. Upload the portfolio files to the repository.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and the `/(root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to publish the website.
9. Copy the published website URL from the Pages settings.
10. Add that URL to the Live Demo section at the top of this README.
